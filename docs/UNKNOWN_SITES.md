## 7. 已知边界（本清单是**下界**，不是全量）

1. **`_` 包裹的小写词干看不见**（`mutex_lock` / `pthread_mutex_lock` /
   `spin_lock_irqsave`）⇒ **同步桶必然偏少**（`mutex_lock()` 是内核 C 最常见写法）。
2. **全大写宏看不见**（`THREAD_CREATE`）。
3. 两者的共同点：形状上和 `__future__`（要排除）**无法区分** ⇒ 下一轮改为
   **并列报第三条口径**（segment：按 `_` 切段、排除 dunder），用两者的**差**
   给出可解释读数，而不是继续调严格形状。
