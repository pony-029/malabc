# R56 —— 把「诚实的边界」的**覆盖口径**从「否定标记词」改成「每一条 bullet」

> 上一轮（R55）给「诚实的边界」的**否定式承诺**接上了反向判据。本轮修的不是产品，
> 而是那台门**自己的准入条件**：V1 只网罗措辞里带 `不识别` / `不做` / `不跟踪` /
> `按兵不动` / `不保证` / `静默` 之一的 bullet，于是 `* Mach-O：` 这句**状态声明**
> （一个标记词都没有）**整条不在网内**。
> 一句话：**不是「判据写错了」，是「判据根本没看它」。**

本轮**零产品行为变更**：`matlabc.py` 一个字节没动，`--help` 仍是 **50451** 字节，
`HELP_BYTES_SNAPSHOT` 不放宽、不改动。

## §2 黑帽：本轮要防的四类静默失效（全部是**跑出来**的，不是推出来的）

| # | 失效 | 现场 | 处置 |

## §9 明确拒绝做的事（避免下一轮走回头路）

1. **不为过门去改产品**：`Mach-O：` 那条**不加**否定词。给它加个「不」字能让标记词口径
   网住它，但那等于**给判据喂噪声**，不是修判据 —— 修的是口径。
2. **不让豁免变成放行后门**：`where` 必须逐字核对（文件 + token 都要真在），
   理由 ≥8 字符，且两向核对（陈旧豁免也红）。
3. **不共享 R51 与 R55/R56 的两台 bullet 解析器**：共享会让两边一起漂而无人发现；
   本轮反而**把「两台一致」写成测试判据 D**。
4. **不改 `HELP_BYTES_SNAPSHOT`、不放宽 `HELP_DRIFT_MAX`**：本轮 `--help` 零改动。
5. **不加门、不动 `MIN_GUARDS`**：本轮是**改口径**，不是加门；门数仍是 13。
6. **不宣称本门的棘轮能拦住「把准入条件改回去」**：已证该因果不成立（§2.4），
   文案已改准 —— 棘轮拦的是「某条 bullet 失去对手方」，这是两条不同的路。
7. **不动 `flow/diagrams`、不动 `VERSION`**（用户明确指示：本轮不修图）。
