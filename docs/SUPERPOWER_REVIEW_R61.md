## §9 明确拒绝做的事（避免下一轮走回头路）

1. **不把新门的判据拆得更细来「凑覆盖面」**：`neg.c` 的「已披露边界」与「不假阳」
   在实现上是同一个集合比较，硬拆两条会让同一个突变体点亮两条 ⇒
   「每条判据各有独立证人」当场失效。做法是把它做成 F6 内部的**登记表** +
   每个 trap 各有突变体。
2. **不为「多一道门更好看」而把 `_c_lex` 搬进 `tools/`**：`tools/` 不 import 产品模块
   是 R52/R54/R55 立下的纪律；要覆盖内部恒等式，就在 `matlabc.py` 的自证里写（C12-2）。
3. **不给新写的散文挂历史豁免标记**：§2.3 那三句的正确修法是改写措辞，
   而不是用 `<!-- guard-count:historical … -->` 把它们洗白 —— 标记是给
   「**举例引用旧值**」用的，不是给「我刚写下的现在时宣称」用的。
4. **不改 `HELP_BYTES_SNAPSHOT`、不放宽 `HELP_DRIFT_MAX`**（本轮 `--help` 字节不变）。
5. **不动 `flow/diagrams`、不动 `VERSION`**（用户明确指示：本轮不修图）。
6. **不把 P4 做成「任何文件里出现 `check_*.py` 就比对」**：那会把历史文档
   （`docs/SUPERPOWER_REVIEW_R*.md`）一起卷进来 —— 它们的数字在写下的那一刻都是真的。
   P4 只在**质量门表那个连续表块**里生效。
