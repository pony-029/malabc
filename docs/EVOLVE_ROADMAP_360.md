# EVOLVE ROADMAP 360 —— 从 Phase 0 到「无红之目标」的 360 轮演进台账

> **定位**：把 R82 方案（`docs/SUPERPOWER_PLAN_R82.md`）的六个阶段摊成 **360 个可记账的轮次**，
> 每轮一次「六顶思考帽 → 真落地 → 隔离探针 → 登记制护栏 → 记账」的闭环。
>
> **时间口径**：360 轮 × 平均 2 分钟 ≈ **720 分钟**。这是**预算**，不是承诺 ——
> 轮次按**真实完成**逐条登记，**不预填、不补记、不伪造**（本仓纪律：
> 「命令说成功了」与「状态真的对了」是两件事）。
>
> **方法**：`superpowers`（六顶思考帽）× `superpower-probe-loop`（隔离探针 + 登记制护栏）
> × `loop-engineer`（闭环与退出条件）。
>
> **台账文件**：仓库外用 `_r82/rounds.jsonl`（追加式，一行一轮，**只增不改**）。

**为什么是这个顺序**（R82 §11）：Phase 0 是唯一「不做就白做」的一步 —— 模型晚定稿 T1–T4

而 T2/T3/T4 都要用它（callback 边就是 T1 的表决定的）。

## 1. 一轮的**标准形状**（每轮都长这样，不许简化）

```
① 蓝帽开场   本轮对象 / 目标 / 产出格式（一份复盘条目 + 真实代码改动）
② 六顶思考帽 白(实测事实) → 红(直觉) → 黑(风险) → 黄(价值) → 绿(替代) → 蓝(收束)
③ 真落地     改哪个文件、加什么、挖出什么真缺陷（**拒绝占位、拒绝 TODO**）
④ 隔离探针   先跑真实 API 拿到真实数字，**再把断言写到真实结果上**
⑤ 登记制护栏 把修复点用 check_*.py 的判据锁死，并**两向自证**（坏要红、好要放行）
⑥ 记账       往 _r82/rounds.jsonl 追加一行：{轮, 阶段, 目标, 变化量, 判据, 结论}
```

**六条不可省的纪律**（全部来自本仓已付过的学费）：

| # | 纪律 | 它防的是哪一类失败 |
|---|---|---|
| D1 | 判据用**恒等式**，不用阈值 | 阈值是在某个语料上调出来的，换规模必失效 |
| D2 | 报「全覆盖」必须**同时报分母** | 没有分母的「全」是不可证伪的话 |
| D3 | 每条判据都要有**能单独打红它**的变异 | 说不出对手方的断言是装饰 |
| D4 | 先装闸门、**看它当场红**，再修 | 先修后装 ⇒ 拿不到「它曾经红过」的记录 |
| D5 | **红灯第一嫌疑人是探针自己** | 探针的期望比被测实现更容易错 |
| D6 | 记账的**变化量必须能被独立重算** | 自报的数字不是证据 |

## 3. 记账格式（`_r82/rounds.jsonl`，一行一轮，只增不改）

```json
{"round": 0, "phase": "0", "line": "base", "objective": "统一图模型 + U1–U5 护栏",
 "changed": ["unified_graph.py", "binhops.py", "concurrency.py", "translate/rules.py",
             "tools/check_unified_graph.py", "+7 处门数级联"],
 "metric": {"before": {"gates": 17}, "after": {"gates": 18}},
 "criteria": ["check_all rc=0 且门数下限 18", "check_unified_graph --selftest bad=16/good=3"],
 "verdict": "accepted", "wall_s": null, "evidence": "commit <sha>"}
```

**`metric` 必须是可独立重算的量**（D6）：`gates` 由 `tools/check_help_contract.py::real_guard_count()` 重算，
`bad/good` 由 `--selftest` 的 `SELFTEST COUNTS` 行重算 —— 都不是自报。

## 4. 退出条件（`loop-engineer` 的停机判据）

循环**只在**下面两个条件之一成立时停机：

1. **达标停机**：`EVOLVE_TARGETS` 里**所有**注册目标的判据皆为绿 ⇒ 停机，
   并交出**「最后一道门的名字」**（不是日期 —— 日期不可重算）。
2. **不可自证停机**：任何一轮出现「判据无法被独立重算」或「缺输入」
   ⇒ **立即停**并把现场交回给人，**不猜、不跳过、不降级成绿**。

**不允许**的停机理由：「跑了 360 轮了」「时间到了」「看起来差不多了」。
轮次与时间都是**预算**，不是**判据**。

## 5. 诚实边界（写进方案里，防止过度承诺）

1. **本轮次表是预算，不是承诺**：360 与 720 分钟是**上限**，实际轮次按真实完成登记。
   一轮没做完就记 `in_progress`，**不记 `accepted`**。
2. **Phase A–E 的产品代码今天一行都没写**：本表登记的是**计划与判据**，
   状态列全部从 ⬜ 起步，逐轮回填（与 `SUPERPOWER_PLAN_R82.md` 同一条纪律）。
3. **不保证 360 轮一定达标**：若在某个阶段发现「目标本身不可自证」，
   正确的动作是**停并交回**（§4 条件 2），而不是把判据放松到达标。
4. **`unknown` / `unevaluated` / `unverified` 是一等状态**：它们的**分母**与
   **可见性**才是「完成」的度量，不是它们的**消失**。
