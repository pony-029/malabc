# 前端使用指南（快捷键 · 命令面板 · 可分享深链）

> 面向**使用生成产物的人**（而非开发本工具的人）。
> 对应版本：v1.16.54 ｜ 所有能力均离线可用、零依赖、无需服务器。

生成的站点（`--browse`）与报告（`--html`）具备一套统一的交互层。本指南说明**怎么用**。

---

## 一、全局快捷键

| 按键 | 作用 |
|---|---|
| `Ctrl+K` / `Cmd+K` | 打开命令面板 |
| `/` | 打开命令面板 |
| `?` | 显示快捷键帮助浮层 |
| `Esc` | 关闭任意浮层 |
| `t` | 切换暗色 / 亮色主题（**会记住**） |
| `g` | 跳到「概览」 |
| `d` | 跳到「重复代码」 |
| `h` | 跳到站点首页 |
| `Tab` | 首个可聚焦元素是「跳到主内容」（键盘/读屏用户直达正文） |

主题偏好存在浏览器本地，刷新后保持；也可用 URL 覆盖：`index.html?theme=dark`。

---

## 二、命令面板（Ctrl+K）

一次搜索覆盖五类目标：**函数 / 文件 / 目录 / 全局变量 / 源码全文**。

- **模糊匹配**：不必输入连续片段。`fda` 能命中 `fooDetailA`；
  排序优先级为「完全相等 > 前缀 > 词首（`_`/`.`/`/` 或 camelCase 边界）> 子串 > 子序列」。
- **最近访问**：面板打开时直接展示最近打开过的条目，自动去重、保留 12 条。
- **Enter** 跳转到目标；**Shift+Enter** 跳转到「全局状态」页并预置搜索（链接可分享）。
- **悬停**搜索结果时，页面上的调用图会脉冲高亮对应节点（仅在该页有调用图时生效）。

### 限定搜索范围（scoping）

结果太多时，用前缀限定类别——**范围越窄，命中越准**：

| 前缀 | 范围 | 示例 |
|---|---|---|
| `fn:` | 仅函数 | `fn:process` |
| `file:` | 仅文件 | `file:util` |
| `dir:` | 仅目录 | `dir:src` |
| `var:` | 仅全局变量 | `var:counter` |
| `@` | 仅源码全文 | `@TODO` |
| `>` | 仅命令 | `>主题` |

只输入前缀（如 `fn:`）即**列出该类别全部**，便于浏览。限定生效时面板顶部会显示提示条。

### 结果分组与预览

- 结果按「命令 → 函数 → 文件 → 目录 → 全局变量 → 全文」**分组**显示，
  同类聚在一起，每项带一行说明（位置 / 路径 / 定义处 / 作用）；
- 选中某项时，右侧**预览面板**显示详情而不跳转：函数的圈复杂度、扇入/扇出、
  风险标记；全文命中的整行并高亮关键词。窄屏下预览自动堆叠到下方。

### 命令模式（执行动作，不只跳转）

面板不只用来跳转，也能**执行命令**：

| 输入 | 效果 |
|---|---|
| `>` | 列出当前页面**全部可用命令** |
| `>主题` | 按名称过滤命令 |

可用命令示例：切换暗色/亮色主题、复制本页链接、回到站点首页、打开统一代码结构图、
打开风险度量、打开重复代码分析、打开函数详情索引、打开全局状态页。

> **命令会按页面自动适配**：报告（`--html`）是自包含单文件，没有站点内其它页面，
> 因此只显示「切换主题 / 复制本页链接」——不会出现点了跳到不存在页面的命令。

> 报告（`--html`）是**自包含单文件**，没有详情页可跳。此时命令面板会把函数
> 定位到**报告内部的锚点**（热点图或度量表对应行）；定位不到就不显示该项——不会出现死链。

## 三、可分享深链

所有视图状态都会同步到 URL，**复制链接即等于分享当前视图**。

### 1. 源码行 / 行区间

| 形式 | 效果 |
|---|---|
| `#L42` | 高亮第 42 行并滚动到视野内 |
| `#L42-58` | 高亮第 42–58 行（区间） |

**点击行号**即可一键复制该行的链接，直接发给同事讨论"这一行"（复制结果会在屏幕底部提示，不会静默无反应）。

### 源码行上的内联诊断

函数定义行会直接挂出该函数的分析结论，**不必跳转到别的页面对照表格**：

`复杂度 7 · 调用 3 · 被调用 12`

- **高复杂度**（≥15）或**高扇入**（≥8）会用黄色告警样式突出；
- 点击徽章直接打开该函数详情页。

### 2. 调用图视图（站点首页）

| 参数 | 含义 |
|---|---|
| `cgmin` | 最小入度过滤（只看被依赖足够多的节点） |
| `cglbl` | 是否显示全部标签（`1` 开 / `0` 关） |

例：`index.html#cgmin=2&cglbl=1` → 打开即为"只看高扇入 + 显示全部标签"的视图。

### 3. 全局状态页

| 参数 | 含义 |
|---|---|
| `tab` | 页签：`g` / `p` / `d` / `t` / `dg` |
| `q` | 搜索词 |
| `f` | 筛选 |
| `sort` | 排序 |
| `page` | 分页 |

例：`global_state.html#tab=d&q=fooA` → 直接定位到该函数相关的重复代码。

> URL 优先级高于本地偏好，且默认值（如 `f=all`、`page=0`）不会污染链接。

## 四、离线与内网

本站点的**主要使用场景是无外网的内网环境**。生成时加 `--offline`：

```bash
python matlabc.py <源码目录> --browse site --offline
```

产物**零外部引用**（不加载 MathJax / Mermaid CDN），公式与图形自动回退为可读的静态源码，
双击 `index.html` 即可打开。

---

## 五、调用图的键盘操作

调用图节点可完全用键盘操作（无需鼠标）：

| 按键 | 效果 |
|---|---|
| `Tab` / `Shift+Tab` | 在节点间移动焦点 |
| `空格` | 聚焦 / 取消聚焦当前节点（等价单击，会叠加其调用链路） |
| `Enter` | 打开该节点对应的源码页（等价双击，新标签页打开） |

## 六、无障碍

- 每个页面都有 `lang`、`skip-link`（跳到主内容）与 `<main>` 语义地标；
- 浮层支持键盘操作，关闭后焦点会归还给触发元素；
- 命令面板结果可用 `↑` `↓` 选择、`Enter` 跳转；
- 尊重系统偏好：**减少动效**（`prefers-reduced-motion`）时脉冲高亮与平滑滚动会关闭；
  **高对比度**（`prefers-contrast`）时提升边框与文字对比；
- 复制类操作会通过**屏幕底部提示条**给出成功/失败反馈（不会静默无反应）。

## 七、移动端 / 窄屏

- 所有页面都带 `viewport`，在手机/平板上按设备宽度渲染；
- 窄屏下宽表格（如 12 列的度量表）可**横向滑动**查看，不会被挤成竖条；
- 命令面板与顶部导航在窄屏自动适配（面板宽度随屏、导航换行）。

## 八、代码审查工作台（compliance.html）

站点不只是「看代码」，还会依据 **MathWorks 官方审查标准**
（matlab-agentic-toolkit 的 matlab-review-code / matlab-modernize-code）
直接告诉你要改什么。

- **合规得分卡**：按官方严重度加权（error ×8 / warning ×3 / suggestion ×1），0–100 分；
- **发现清单**：按 `error（必须改）> warning（应该改）> suggestion（可改）` 三级分组，
  每条都给出**怎么改**；
- **按文件下钻**：按严重度排序，一眼看出先改哪个文件。

覆盖四类检查：

| 类别 | 例子 |
|---|---|
| 命名约定 | 函数应 lowerCamelCase；文件名应与主函数名一致 |
| 函数质量 | 参数 >6、返回值 >4、长度 >50 行、嵌套 >3 层、复杂度 ≥15、缺 H1 帮助行 |
| 现代化 | `datenum`→`datetime`、`csvread`→`readmatrix`、`eval`→函数句柄等 |
| 可移植性 | 硬编码反斜杠路径 |

源码页里，用到废弃/不推荐 API 的行会直接挂出 `⚠ csvread → readmatrix` 标记，
悬停可看官方推荐的替代方案（高危动态执行标红）。

### 需要人工复核

官方明确指出 **checkcode / Code Analyzer 查不出**以下项目，本工具自动检出并集中提示：
魔数、遮蔽内置函数（如 `sum = 0`）、深层嵌套、缺 H1、硬编码路径。

> 请注意：**自动检查没报 ≠ 没问题**。
> 另附官方原文要点：**`subplot` 并未废弃**，只是新代码推荐
> `tiledlayout`/`nexttile`，不要盲目替换。

## 九、自查：我的产物有问题吗？

本地一条命令，与 CI 门禁完全一致：

```bash
# 标准
python fe_audit.py <源码目录> _out

# 内网交付（更严：要求零外部引用）
python fe_audit.py <源码目录> _out --offline --enforce-offline
```

审计 11 项：JS 语法、内部死链、外部 CDN、锚点、运行时异常、交互接线、孤儿页面、
脚本内死链、无障碍基线、硬编码导航路径、真实 DOM 交互。

退出码：`0` 通过，`1` 存在错误（阻断），`2` 仅有警告且开了 `--strict`。

> 想启用"真实 DOM 交互"检查（S11），需 `npm install --no-save jsdom`；
> 缺失时该项降级为警告，不阻断。
