## §1 N2：我漏读的一条对手方

报错原文：

```
N2 matlabc.py: 期望至少有 1 处**未被豁免**的「N 道护栏」类宣称，实际 0 处
    —— 覆盖被静默取消了（rc 依然是 0，所以必须抓）
```

它的意义很清楚：**「我把数字改成模糊表述」这种动作，正是一条覆盖声明被删除的典型路径**。
如果允许「全部登记制护栏」这种写法，那么把「24 道」写成「3 道」也不会有人发现。

⇒ R110 §6 / R114 建议 1 里那句「把数字只留 README」是**错的方向**。
正确方向只能是：**数字必须留，且改它必须付一次整树重跑**。这也解释了 R108 §12 为什么把
「改 `matlabc.py` 任何字节 ⇒ 与整树重跑同轮」写成硬规矩——**它不是懒，它是被 N2 与 W2 夹出来的唯一解**。
