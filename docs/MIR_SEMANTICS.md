# MIR 语义规范

> **这份文档是规范，不是说明。** `mlc_ops.c` 是它的一个实现；两者不一致时以本文为准，
> 并且要么改实现、要么改本文 —— 但不能"以实现为准"。
>
> 为什么现在写它：D4（泄漏专项）连续两轮撞在同一处 —— **`mlc_array_init` 是"构造"还是"重置"从来没定义过**。
> 同一个改动，在"构造"语义下是修 bug，在"重置"语义下是引入崩溃。规范缺失的代价就是这种。

## 一、数据模型

```c
typedef struct {
    mlc_dtype dtype;                  /* 本规范只定义 MLC_F64 / MLC_I64 */
    int32_t   ndim;
    int64_t   shape[MLC_MAX_DIMS];    /* 8 维上限 */
    int64_t   strides[MLC_MAX_DIMS];  /* **行主序**：strides[0] = 最后一维长度 */
    int32_t   owns_data;
    void     *data;
} mlc_array;
```

三条不变量：

1. **行主序**：`strides[ndim-1] == 1`，`strides[k] = strides[k+1] * shape[k+1]`。
   已知反例：`mlc_op_col` 曾用 `i + (j-1)*strides[1]`，在 2×3 上算出 `2 3`（正确 `2 5`）。
2. **值语义**：MATLAB 赋值是复制；本运行时**不实现别名**，`y = x` 判为不支持（见第四节）。
3. **谁分配谁释放**：`owns_data=1` 才由 `mlc_array_free` 释放；`mlc_array_view` 产出 `owns_data=0`，**不得**释放。

## 二、五条通用规则

| # | 规则 | 含义 | 当前实现 |
|---|---|---|---|
| G1 | **`init` 是"构造"** | 对同一对象再次 `init` 是**未定义**（旧缓冲不会被释放）。调用方必须先 `free` 再 `init` | [!] 未强制：`memset` 直接抹掉旧指针（D4 的 S2/S3 即此） |
| G2 | **输出缓冲由调用方提供** | 除 `*_alloc` 家族外，算子只写 `out`，不分配 | [OK] |
| G3 | **空输出 = 授权就地分配** | `numel(out)==0` 时，算子按结果形状 `init(out)` —— 这是 dynshape 的唯一入口 | [OK] 仅 ADD/SUB/MUL/DIV、SUM/MAX/MIN/MEAN、TRANSPOSE、FIND/COLRANGE |
| G4 | **不猜** | 形状不符、越界、dtype 不符 → `MLC_ERR`，绝不截断、绝不按 1 元素猜 | [OK] |
| G5 | **求值顺序** | 每条 MIR 语句从左到右求值；嵌套表达式在翻译期已拆成多条语句，**MIR 里没有嵌套表达式** | [OK] |

## 三、算子逐条（42 个，8 族）

字段含义：**dtype**（输入/输出类型）｜**形状**（输出形状规则）｜**所有权**（谁分配）｜**错误**（触发 `MLC_ERR` 的条件）。

### 3.1 逐元素·二元（广播）

| 算子 | 形状 | 错误 |
|---|---|---|
| `OP-ADD` `OP-SUB` `OP-MUL` `OP-DIV` | 广播：逐维取 max（任一维为 1 或相等）；输出为空时按广播结论就地分配 | 不可广播；`out` 形状与广播结论不符；`data` 为 NULL；非 f64 |

> `OP-MUL` 与 `OP-MATMUL` 的区别：MATLAB 的 `*` 在**标量参与**时是逐元素，双方都是 2-D 且内维匹配时才是矩阵乘。
> 发射器按「是否有标量 / 是否 2-D 且内维匹配」二选一（R550 曾因正则把 `*` 直接映射成 MATMUL 而算错）。

### 3.2 逐元素·一元

| 算子 | 语义 | 形状 |
|---|---|---|
| `OP-SQRT` `OP-ABS` `OP-EXP` `OP-LOG` | √、绝对值、指数、自然对数 | **与输入完全相同**（不广播、不改形状） |
| `OP-SIN` `OP-COS` `OP-TAN` | 三角函数 | 同上 |
| `OP-FLOOR` `OP-CEIL` `OP-ROUND` | 取整（`round` 为四舍五入，非 banker's） | 同上 |
| `OP-LOG2` `OP-LOG10` | 以 2 / 10 为底 | 同上 |

**共同错误**：输出 `numel != 输入 numel` → `MLC_ERR`（不允许算子"顺手改形状"）。

### 3.3 归约（结果恒 1×1）

| 算子 | 语义 | 形状 |
|---|---|---|
| `OP-SUM` `OP-MAX` `OP-MIN` `OP-MEAN` | 全部元素归约 | **1×1** |
| `OP-ANY` `OP-ALL` | 是否存在 / 是否全为非零 | 1×1（0 或 1） |
| `OP-NNZ` | 非零个数 | 1×1 |
| `OP-ISREAL` `OP-ISNUMERIC` | 类型谓词（本运行时数据只有 f64 实数 → 恒 1） | 1×1 |

**共同错误**：`numel(out) != 1` → `MLC_ERR`；输入 `numel==0` 时 `ALL` 取 0、`ANY` 取 0（与 MATLAB 一致）。

| `OP-ISEQUAL` | `isequal(a,b)`：同形且逐元素相等 -> 1 | 1×1 |
| `OP-ISEQUALK` | `isequal(a,k)`：`a` 必须 1×1 且等于 `k` | 1×1 |

### 3.4 归约·取维度（结果恒 1×1）

| 算子 | 语义 |
|---|---|
| `OP-SIZE` | `size(a, dim)`；`dim` 超出 `ndim` → 返回 **1**（MATLAB 语义），不是错误 |
| `OP-LENGTH` | `max(size(a))`（空数组为 0） |
| `OP-NUMEL` | 元素总数 |
| `OP-ISEMPTY` | `numel == 0` |

### 3.5 切片 / 下标

| 算子 | 语义 | 形状 |
|---|---|---|
| `OP-INDEX` | 线性下标（1-based） | 1×1 |
| `OP-ROW` | `A(i,:)` | 1-D，长度 = 列数 |
| `OP-COL` | `A(:,j)` | 1-D，长度 = 行数 |
| `OP-SLICE` | `x(lo:hi)`（1-D） | 长度 `hi-lo+1` |
| `OP-COLRANGE` | `A(:,lo:hi)`；`hi<0` 表示 `end` | 2-D `[行数, hi-lo+1]`；输出为空时就地分配 |
| `OP-MASK` | `x(x>k)` 逻辑索引 | 长度由命中数决定，**自己分配** |

**共同错误**：下标 < 1 或 > 维度长度 → `MLC_ERR`（不截断）；对非 2-D 用 `ROW/COL/COLRANGE` → `MLC_ERR`。

### 3.6 布局

| 算子 | 语义 | 形状 |
|---|---|---|
| `OP-TRANSPOSE` | `A.'` | `[c, r]`（原 `[r, c]`） |
| `OP-FLATTEN` | `A(:)`，**列优先**顺序 | 1-D，长度 = numel |

### 3.7 线性代数

| 算子 | 语义 | 形状 | 错误 |
|---|---|---|---|
| `OP-MATMUL` | `A*B` | `[A.m, B.n]` | 任一方非 2-D；`A.n != B.m`（**生成期就拒绝**，不留到运行时） |

### 3.8 返回下标

| 算子 | 语义 | 形状 | 错误 |
|---|---|---|---|
| `OP-FIND` | `find(x cmp k)`，1-based 下标 | 长度由命中数决定，**自己分配** | 比较码/阈值非字面量 |
| `OP-FIND2` | `find(a cmp b)`，逐元素比较**两个等长数组** | 同上 | **两数组 numel 不等** → `MLC_ERR`（不猜） |
| `OP-FIND3` | `find(x, n)`，前 n 个 | 同上 | n 非字面量 |

> `OP-FIND` 与 `OP-FIND2` 是**两种算子**：前者右侧是标量阈值，后者右侧是等长数组。
> R555 曾把后者当后者实现，结果 `findeq` 只命中 1 个（Octave 是 4 个）。

### 3.9 写入

| 算子 | 语义 | 前置条件 |
|---|---|---|
| `OP-SETIDX` | `a(i) = v` | `a` 必须**已定尺寸**；越界 → `MLC_ERR` |

### 3.10 控制流（提前退出）

| 构造 | 语义 | 发射 |
|---|---|---|
| `return`（MIR `return`） | 提前结束本函数，保留已写入的返回值 | `goto m2c_cleanup;` |
| `fail`（来自 `error(...)`） | 以 `MLC_ERR` 结束（端口无异常/消息通道） | `st = MLC_ERR; goto m2c_cleanup;` |

两者的落点 `m2c_cleanup:` **只在函数里真出现过这两者时才生成**（其余函数生成物逐字节不变）；
落点负责释放临时量后 `return st;` —— 先有落点、再有跳转，否则就是悬空 `goto`（R578 踩过）。

## 四、明确**未定义**的东西（比"已定义"更重要）

| 项 | 现状 | 后果 |
|---|---|---|
| **`init` 的重复调用** | 未定义（G1 只写了"是构造"，但实现会静默泄漏） | D4 实测 S2/S3 各泄漏 1 次；已用债务锁钉住 |
| **别名** | `y = x` 判为不支持 | MATLAB 值语义未实现；一旦放行会静默共享缓冲 |
| **形状求解深度** | `emit.rs` 里 `depth >= 3` 就放弃 | 这不是环检测，是"再深我就不管了"；深层嵌套会被判"形状推不出" |
| **`global`** | 不支持 | 忽略会让回调读到 0（静默错值），所以一律拒绝 |
| **归约算子的 2-D 语义未统一** | `OP-SUM` 已按 MATLAB 沿第一个非单例维（2×3 → 1×3）；`OP-MEAN/OP-MAX/OP-MIN` 仍走 `mlc_reduce_prepare` 的**全元素归约**（恒 1×1） | 同一段代码里 `sum(A)/numel(A)` 与 `mean(A)` 在 2-D 上给出**不同结果**；差分测试对 `mean` 的 2-D 用例必然失败 |
| **NaN / ±0 / Inf** | 未规定 | 位精确比较时可能出现假不等 |
| **求值顺序的副作用** | MIR 无嵌套表达式，故无歧义 | 翻译期拆语句的顺序即语义 |
