## 3. 本轮的交付

### 3.1 语料无关的生成器（`_r98/build_corpus_doc.py`）

**一份生成器 · 两种入口 · 三种语言**：`--lang py|js|c|matlab`。
语言差异**不散落在代码里**，全部收在两处：

```python
LANGS = {"py": {...}, "js": {...}, "c": {...}, "matlab": {...}}   # 一句话口径 + 能力
def recompute_py(files):      # 名字级：命中即扇出
def recompute_matlab(files):  # 限定名级：照 matlabc.py:32498-32531 重建
```

**生成期恒等式 C1–C10**（每份产物都过）：

| 判据 | 说的是什么 |
|---|---|
| C1 / C2 | `Σfiles[].n_funcs == len(funcs)` / `Σfuncs[].n_calls == 调用点总数` |
| C3 / C4 / C5 | 调用点 == 已解析 + 未解析 / `Σ已解析目标 == len(edges)` / `Σfuncs[].n_in == len(edges)` |
| C7 / C8 | 文件级 `call_out` 合计 == 跨文件边 / `Σheur_stats.by_kind == len(heuristics)` |
| **C9** | **独立复算 == 产物**（py/js **逐条**；matlab **多重集**；c **不等式 + 说明**） |
| C10 | 引擎 cg 产物若在：`Σresolution == edges_total`（**只对产物自己**，不跨口径混算） |

**紧凑存储是「显式」的**：邻居表截断到 `--max-nb`，但**计数在截断前记下**
（`target_total` / `in_total`），页面上写「只列前 N 个」。**截断不上报 = 把「看不全」伪装成「全部」**（R84 的老账）。

### 3.3 口径发现 ①：同一关系的两种序（**量具错**）

引擎的两处写点**故意不同序**：

| 出处 | 序 | 原文 |
|---|---|---|
| `matlabc.py:32498-32531` | **源码调用点序** | 注释：「按首次出现顺序去重…使调用图按代码中的真实调用时序展示（**而非过去的字母序**）」 |
| `matlabc.py:13988` | **字母序** | `"calls": sorted((f"{c.mfile.rel}:{c.name}" …) for c in f.calls)` |

而 `call_sites`（源码序的原始载体）**不进 JSON** ⇒ **只用 JSON 不可能复算顺序**。

**实测（cobratoolbox）**：同一集合 **40,298** 条，顺序不同，**首个不同 @0**：

```
我   : ('.artenolis/generateTutorials.m:generateTutorials',
        'external/analysis/mptoolbox/@mp/length.m:length', True)
产物 : ('.artenolis/generateTutorials.m:generateTutorials',
        'external/base/utilities/findjobj/findjobj.m:ischar', True)
同集合 = True   同顺序 = False
```

**处置**：C9 对 matlab 改成断言**多重集**，并把「顺序不同（产物=源码调用序，
JSON 只给 `calls` 的字母序投影）」**写进明细文本**。
⚠ 关键：**降级的地方要同时把事实升级** —— 不能只是「把断言改松然后闭嘴」。

### 3.4 口径发现 ②：限定名**不唯一**（**量具错**）

真实 MATLAB 里 `classdef` 的属性访问器 `set.X` / `get.X` 是**两个不同成员**，
但派生字段 `name` **都是 `X`**：

```
rel = external/base/utilities/violinPlots/Violin.m
  name=EdgeColor  line=182  kind=method  sig='function set.EdgeColor(obj, color)'
  name=EdgeColor  line=186  kind=method  sig='function [color] = get.EdgeColor(obj)'
```

⇒ `"rel:name"` 撞车。引擎的边是**标签级**的（`edges = list(dict.fromkeys(edges))`
按 `(caller, callee, cross)` 元组去重）⇒ 两条不同的边**塌成 1 条**。

**量化**（cobratoolbox）：

| 读数 | 值 | 说明 |
|---|---|---|
| `label_dup_defs` | **8** | 定义级重复的限定名（**全在 `Violin.m`**） |
| `label_ambiguous` | **1** | 其中**真被调用点引用到**的（两个调用点） |
| `label_overcount` | **2** | 若按**索引级扇出**会多出来的边数 |
| 复现 | `40298 + 2 = 40300` | 与修复前实测的 **40,300 vs 40,298** 逐位吻合 |

⚠ **两个数都必须报**：只报 `1` 会被误读成「全语料只有 1 个不唯一」。

**这一条与 R88「节点身份 = 定义落点」同族**，列为**下一轮候选修复**（改 `functions[].name`
让 `set.` / `get.` 可区分 —— 属**口径类**，须走 R88 的「**边一条不删**」判据）。

### 3.5 `files_located`：把「静默」变成「拒绝落盘」

我第一版把 `--root` 给成了**上一层**（`corpus/sympy` 而不是 `corpus/sympy/sympy`）。
后果**不是报错**，而是：

```
   files              1570
   loc                71        ← 1,570 个文件被数成 71 行
== 自检 9 条，失败 0 条 ==       ← 恒等式全过，因为「数字自洽」
```

**「数字自洽」正是口径类事故的典型形状**（R83 老账：口径错了所有读数会一起错且全都自洽）。

**修法**（不是「把 LOC 修成 0 就算完」）：

```python
if _loc_n < _n:
    print("!! 源文件定位 %d / %d —— 检查 --root 是否与引擎那次分析的 root 一致")
    if _loc_n == 0:
        print("!! 一个源文件都定位不到 ⇒ 拒绝落盘（改对 --root 再来）")
        return 1
```

**退出码契约同时成文**（每个码都必须有真实代码路径，R96 ⑨ 的账）：
`0` 正常 · `1` 拒绝落盘 · `2` 参数错 —— 三码**两向自证**跑过：

```
=== rc=2：参数错（缺 --out）===            rc=2
=== rc=1：源一个都定位不到（--root 给错）===  rc=1
=== rc=0：正常 ===                        rc=0
```

### 3.6 三语料对照页（`_r98/out/compare_three.html`）

**一个数字都不手写**：内核那份来自 `kernel_dashboard_data.json`（看板自己的恒等式计数当对手方），
另两份来自生成器落盘的 `*.summary.json`。页面上显式写出**四条不可比**：

1. **C** 的边经过**两级解析阶梯**（同文件优先 + include 闭包）⇒ 「未解析」不是 py 的那个词；
2. **Python / JS** 是**名字级**：一个调用点命中 N 份同名定义就产 N 条边（**扇出，不是覆盖**）
   —— sympy 的边数高得离谱，主因是它内部有大量同名函数；
3. **MATLAB** 无 `--callgraph` 汇总产物 ⇒ 「解析档位」一栏是**不可用**而不是 **0**（「我没算」≠「它是 0」）；
4. **同一关系的两种序**（§3.3）。

## 4. 六顶思考帽

### ⚪ 白帽（事实）—— 三次「先问量具错还是对象错」

| # | 症状 | 第一反应 | 量出来的真相 | 裁定 |
|---|---|---|---|---|
| 1 | 大文档冒烟 12 条路由**全报** `"undefined" is not valid JSON` | 「内嵌 JS 坏了」 | 我的**桩 DOM 缺了** `<script id="data">` 的 `textContent` | **量具错** |
| 2 | C9 首条就不同 | 「复算口径理解错了」 | 集合差 **0**、`call_sites` 不进 JSON ⇒ **顺序不可复算** | **量具错** |
| 3 | 模型 40,300 vs 产物 40,298 | 「引擎多算了 / 少算了」 | **`label_overcount = 2`**，来源是 `set.X`/`get.X` 同名 | **量具错** |

**三次的教训是同一条**：**先把「我以为的形状」量出来，再问谁错。**
三次里有两次我第一反应都是「对象坏了」。

### 🔴 红帽（直觉 / 情绪）

**「看下效果」这四个字最容易让人偷懒** —— 只要截图好看就能交差。
本轮的直觉警戒线设在：**任何为了好看而放宽的断言，都是把技术债换成幻灯片**。
`loc=71` 那一版**看起来一切正常**（恒等式全绿、页面渲染正常、冒烟 0 失败）——
它是我唯一一次真的想「反正只是对照页少一列」。**没放过它，是本轮最值的一次坚持。**

### ⚫ 黑帽（风险 / 反例）

| 风险 | 现状 | 反例 / 反制 |
|---|---|---|
| 「多重集」会不会变成**空的判据**？ | 不会 | 若两边都是空集，`sorted(mine) == sorted(prod)` **成立**（空 == 空）。反制：`C4/C5/C7` 独立钉住**条数**，且 C2 钉住调用点总数 —— 三者同时为 0 才会让 C9 变空判据，而那会被 C1 抓住（`funcs == 0`） |
| 顺序不可复算 ⇒ **顺序类的真回归**以后还看得见吗？ | **看不见** | 这是**本轮承认的能力损失**。补偿：站点侧（`--browse`）与 `site-quality.json` 是**另一条独立通道**（实测 sympy 站点 `files/functions/edges` 与单文件文档**同数**） |
| 生成器只有**一个**实现，`recompute_*` 会不会跟引擎「一起错」？ | 部分会 | `recompute_matlab` **刻意不复用**引擎代码，只读 JSON 的 `calls`；但它**同源**（都读同一份 JSON）⇒ 只能证「聚合与呈现没错」，不能证「引擎没错」。这条**如实写在 C9 明细里** |
| `label_overcount` 会不会变成「新数旧账」？ | 有风险 | 它是**对照量**（若扇出会多几条），不是产物的数。已写进 C4 明细并注明「按索引扇出会多 N 条」，措辞上是**反事实** |
| 路线图加了槽 36，会不会让环路错乱？ | 已验证 | 环路预检 **0 问题**；槽 25（`py_ast_frontend`）/ 槽 35 的 action **逐字未变**；新槽走**独立线路 `t4`** ⇒ 万一将来被标 blocked 也只停 `t4`，不误伤 `t3` 上排队的 26–29 |

### 🟡 黄帽（价值）

- **对用户**：从「你说分析过了」变成「你点开就能看」——三份文档 + 一份对照页，
  且**每条数字都能被下一次重算**。
- **对项目**：`build_corpus_doc.py` 是**第一台语料无关**的呈现层装置。
  它的价值不在「又做了一个页面」，而在**口径被逼着写出来**：
  `LANGS` 表把「C 有阶梯 / py·js 是名字级 / matlab 是限定名级」变成**代码里的常量**，
  而不是散在注释里的说法。
- **对下一轮**：两处口径发现**都是可执行的入口**（§3.3 的顺序通道、§3.4 的 name 撞车），
  不是「以后再看看」。

### 🟢 绿帽（创造 / 下一步）

1. **把「顺序」变成可算的**：`--json` 里给 matlab 补一个**只存顺序的轻量数组**

   把本轮承认的能力损失收回来。
2. **把 `name` 撞车做成判据**：`entity_model.py`（R97）已经定义了实体契约，

3. **站点侧的跨产物恒等式**：本轮已手工验过 `site-quality.json` 与文档同数
   （1,570 / 38,052 / 1,783,121）—— 值得把它做成生成器的一条**自动**判据。
4. **生成器入库**：R91 的 `build_py_callgraph_doc.py` 入库债仍在，本轮又多一台。

## 5. 与卡帕西四原则对照（用户指令：这是第一原则）

| 原则 | 本轮的具体体现 | 反例（我差点犯的） |
|---|---|---|
| **① 写码前先想清** | `--lang` 差异先收成 `LANGS` 表；先量吞吐（2 s / 47 s）再决定要不要做全量 | 差点**直接**写「一个语料一个生成器」——那就是把 C/Py/MATLAB 的差异复制三遍 |
| **② 极简优先** | 只有**一份**生成器；邻居表用**小数组** `[target_i, line]` 而不是 dict；载荷瘦身只删**空键** | 差点为「通用性」做一个插件式 renderer 注册表 ——**没有被要求** |
| **③ 手术式改动** | `matlabc.py` **零改动**；两处修改都只动 `_r98/` 里的仓外脚本；路线图**只追加**、不重排既有槽 | 差点顺手「把 `functions[].calls` 改成源码序」—— 那是**引擎口径类改动**，牵动 edges/checks/GUI 多处 |
