## §2 黑帽：本轮抓到的问题（含诚实声明）

### 2.1 真缺陷：三条「替代装置」在帮助与两侧 README 里**各 0 次**

- **它是什么**：`--help` 说「不解析 `dlopen`/`dlsym` 的运行期绑定」，
  但**没有告诉用户那该用什么**。边界写成了**死胡同**而不是**可执行的话**。
- **为什么是真缺陷而不是洁癖**：用户读完这条只知道「它不干」，
  于是要么放弃、要么误以为它能查。点名三个现成装置，这条边界才**可执行**。
- **修法**：动态库那条 bullet 补写替代装置；两侧 README 同步。
  正文里没有新开关、新依赖、新门（`MIN_GUARDS` 仍是 11，散文里的
  「11 道护栏」**不变**）。

### 2.2 真缺口：「诚实的边界」整节**没有装置**

- R50 §5 刚量出过同一种病（`.exts` 是一句**声明**，声明与行为分叉时没人看得见）。
  R51 在**文档层**又遇到一次：8 条边界承诺，`tools/` 里 0 处断言。
- 后果：下一轮改代码时某条边界被挪走或改写成反话，**没有任何东西会响**。
- 修法：R51 把登记表与帮助正文做成**互为对手方**（B1 未登记 → 红、
  B2 陈旧 → 红、B3 逐字 → 红、B4 理由太短 → 红、B5 文档同源 → 红）。

### 2.3 诚实声明（**本轮不假装**）

- **B1–B3 保证的是「登记表 ↔ 帮助互为对手方」，不保证 bullet 的**内容**是真的。**
  一句错话照样能过 R51；内容的正确性靠 review 与 B3 里**显式列出**的 token。
  这与 R3「完整性棘轮不是质量判据」是同一句话。
- **B5 至今只覆盖「运行期绑定」这一条**（只有它有 `docs`/`docs_must`）。
  其余 7 条**没有** README 侧对手方 —— 这是**已知覆盖缺口**，写在这里，
  由 §8 C''''''7 接手。
- **本轮未做大规模语料扫描**：这条边界在**声明层**，行为侧由独立探针在合成
  与真实文档上量；不涉及 `binfmt` 行为改变。

### 2.4 自伤一处（被装置当场抓到）

补丁脚本第一版把锚点里的**内层双引号**写掉了
（`all(ch in "─-=~—" for ch in body)` 写成了 `all(ch in ─-=~— for ch in body)`），
补丁**在写盘前**就 ABORT（锚点命中 0 次）—— 「全或无 + 锚点恰好 1 次」这条纪律
在本轮又一次直接阻止了一次坏写盘。

## §3 黄帽 / 绿帽：收益与边界

**收益**

1. **承诺变成可证**：8 条边界逐条与登记表对账，任何一条被挪走/改写 → 红。
2. **反向判据真实存在**：把新装置与新测试放进**干净 `HEAD` 工作树**，
   两条 R51 测试**都红**（见 §6）；恢复后两条绿。
3. **文档缝被显式堵住**：B5 要求帮助与两侧 README **同源**，
   否则「帮助说了、README 没说」会立刻变红。
4. **数字不是手写的**：`nb == len(BOUNDARY_CLAIMS)` 是**互为对手方的直接后果**，
   没有魔法数字 —— 加一条 bullet 就必须同时加一条登记（否则 B1 红）。

**边界（不假装）**

- R51 是**静态**判据：它证明「登记表与帮助对得上」，**不**证明 bullet 内容为真。
- 「首行前缀」认领要求前缀唯一；两条 bullet 共用一个前缀时 B2 直接报**歧义**
  （不许蒙对），而不是悄悄认领第一条。
- **未引入任何新依赖 / 新门**：`MIN_GUARDS` 仍 11。

## §4 蓝帽：本轮建立的不变量

1. **「诚实的边界」小节是登记制契约**：小节里每条 bullet 必须被
   `BOUNDARY_CLAIMS` **恰好一条**认领（未登记 / 陈旧 / 歧义都是红）。
2. **逐字不变量**：登记项声明的每个 token 必须**逐字**出现在它认领的 bullet 全文里。
3. **理由不变量**：每条登记必须携带 ≥8 字符的理由；理由过短的登记**不生效**
   （防止「一个字符永久关掉一条边界」）。
4. **文档同源不变量**：带 `docs` 的登记，其 `docs_must` 必须在所列文档里逐字出现。
5. **替代装置是单一事实源**：`RUNTIME_BINDING_TOOLS` 一处定义，
   帮助正文、`README.md`、`README_CN.md` 三处都必须逐字命中。
6. **体积棘轮不变量**：合法增长必须在**同一提交**里更新快照，`HELP_DRIFT_MAX` 不动。
