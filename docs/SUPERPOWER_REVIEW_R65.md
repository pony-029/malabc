### §1.2 真正的缺陷：两类漂移在网外

K1–K6 全是**静态**的 —— 它们证明「登记与源码里的引用一致」，**不证明登记说的结局是真的**。

| 漂移 | 为什么静态判据看不见 |
| --- | --- |
| 把一条红测试改成先 `pytest.skip` 再绕过所有断言 | K4 只查源码里**有** `pytest.skip` 字样 ⇒ 照样放行 |
| 把某条红测试**真的修绿**（改用一条不需要缺失产物的路径） | 只要它仍写着那个 basename ⇒ K1 全绿、K2 也不动 |

**「实测」两个字必须有量具撑着 —— 否则它比不写更糟，因为它让人以为有人量过。**

## §2 黑帽：这一版**不解决**什么

1. `--measure` 是**选修**，不在 `check_all.py` 的默认路径里 ⇒ 只跑 `check_all`
   的人不会执行它。它的真调用者是 `tests/test_matlabc.py` 里的一条测试。
   （这是**有意的**：`check_all` 必须能被没有 pytest 的解释器跑通。）
2. 它只跑**已登记**的 nodeid ⇒ 一条**新的**、引用了**未登记**缺失产物的红测试
   仍看不见（K1 只扫「已登记产物的 basename」）。
3. K7–K9 说不清「登记陈旧」与「产品被修好」的区别 —— 它只说「不符」。
4. README 表行里的 **47 / 8 / 4** 依然没有**门**的对手方：门只在 `--measure` 下
   打印实测数，默认路径打印的仍是**登记表长度**。（C14-2 只前进了一步。）
5. `measure_outcomes` 依赖 `--junit-xml`（pytest 自带选项，非插件）。若未来 pytest
   大改该选项，本模式会 rc=2（**会响**，不会静默）。
6. 解释器：`--measure` 用 `sys.executable`；用无 pytest 的解释器跑只会看到
   rc=2 加一段 ImportError 尾巴，没有「请换解释器」的指引。
7. 「在测试里点名一个已登记产物 = 一条登记义务」这条教训只落在**一条注释**里
   （不在任何门的管辖内）。

## §3 落地物（全部真实现，无占位符）

### §3.1 `measure_outcomes(root, names, ...)` —— 实测的**装置**

真跑 `tests/test_matlabc.py::<name>` 集合，用 pytest 自己的 `--junit-xml` 取结局。
**不解析 `-q` 的人读输出**：本机实测 `-rf` **不打印** FAILED 段（R63 记下的坑），
解析文本会**静默少算**。返回 `(结局 dict 或 None, info)`；收集不到的名字**不出现在
dict 里** —— 所以「缺键」是信息，不是错误。

### §3.2 `classify_measured(measured, red, skip, green)` —— 纯函数

| 判据 | 对手方（什么会红） |
| --- | --- |
| **K7 红不红** | RED 桶里某条实测**不是** failed/error ⇒ 红（`passed` = **红变绿**；`skipped` = **红变跳过**；收集不到 = 名字没了） |
| **K8 绿不绿** | `GREEN_REFS` 桶里某条实测**不是** passed ⇒ 红（那条「其余绿」的前提破了） |
| **K9 跳不跳** | `SKIP` 桶里某条实测**不是** skipped ⇒ 红（它不再跳了） |

纯函数 = 可被 `--selftest` 用**合成分布**两向驱动，不需要 pytest（自证仍是秒级）。

### §3.3 `--measure`：机器可读行 + 三档退出码

```
MEASURE COUNTS {"failed": 47, "passed": 4, "skipped": 8, "error": 0, "not_collected": 0}
check_known_red: --measure OK（真跑 59 个登记的 nodeid，… 秒；实测 红 47 / 绿 4 / 跳过 8 与登记桶 47/4/8 逐条相符；判据族 K7–K9）
```

（**只有** `MEASURE COUNTS` 那一行是逐字引用 —— 三个数由实测给出；OK 行里的墙钟
是**次数相关**的读数，不逐字固化：本轮测到 pytest 自身 **4.8 秒**、门整体
**8.0 / 5.1 秒**（同一台机器、同一解释器，差异来自模块导入缓存）。）

`rc`：`0` = 逐条相符；`1` = 有漂移（打印每条 K7/K8/K9）；`2` = 缺输入
（pytest 起不来 / 没产出 junit XML）—— **缺 pytest 时不许静默放行**。

### §3.4 `--selftest` 加样本：7/1 → **12/2**

新增 1 个好样本（实测分布与登记桶一致）+ 5 个坏样本（K7 红变绿 / K7 红变跳过 /
K7 收集不到 / K8 绿变红 / K9 跳过变绿）。

### §3.5 签名与文档口径

`ROW_SIGNATURE`：`K1–K6` → **`K1–K9`**。同步改了 6 处：本门 docstring（新增实测半
一节）、两侧 README 的表行、`CONTRIBUTING.md` 的小节标题与「静态半」措辞、
`tools/check_help_contract.py` 的 `GUARD_CONTRACT` 文案；两侧 README 的表行**同时**

`docs/SUPERPOWER_REVIEW_R63.md` 里的 `K1–K6` **保持原样**（那是历史记录）。

### §3.6 真调用者：一条四层测试

`tests/test_matlabc.py::test_r65_measure_half_two_way`：

1. 端到端跑 `--measure`，rc=0，且 `MEASURE COUNTS` 的三个数与三个登记桶的**长度**逐项相等；
2. 用 `measure_outcomes` 取**真结局**驱动 `classify_measured` ⇒ 零漂移；
   再把一条**实测为 passed** 的真测试谎报成「已知红」⇒ 必须报 K7；
   把一条**实测为 failed** 的真测试谎报成「其余绿」⇒ 必须报 K8
   （**反例用的是真测量数据**，不是合成样本）；
3. 静态半**不依赖 pytest**：拿一个「import 就炸」的假 `pytest` 挡在 `PYTHONPATH`
   前面，默认路径照样 rc=0，且**不打** `MEASURE COUNTS`；

### §5.1 本轮的自伤（都被抓、都已处置）

1. **补丁脚本里我手搓了一个「要替换的锚点自身」的字符串字面量**：第一版把
   `_GOOD_TEST = '''...'''` 塞进新函数块的结尾，既造出非法的
   `def _GOOD_TEST = ...`，又在 Edit 时把那段的闭合 `'''` 删掉了 ⇒ 解释器两次
   报 `SyntaxError`。**两次都是当场就报的**（比静默好），但白烧两轮。
   教训：**别手工拼装「内容里包含自己锚点」的字符串** —— 把锚点与新增块分开两个变量。
2. **这道门当场抓到了我新写的测试**：反例里我用 `fe_audit.py` 当哑元产物名，
   而 `scan_refs` 按 basename 扫**全文（含 docstring）** ⇒
   `K1 fe_audit.py 被 test_r65_measure_half_two_way 引用了，但它没有登记`。
   这正是本门 docstring 里写明的取舍（「宁可多登记一条」）。
   **处置**：反例判的是**测试名**，产物只是占位 ⇒ 换成**未登记**的哑元名
   （而不是让 `GREEN_REFS` 从 4 涨到 5、再连带改两侧 README 的数字），
   并在测试里写下注释说明「点名已登记产物 = 一条登记义务」。
   ⚠ 这是**跨轮第三次**撞在同一处（R56/R63 各一次）：**登记面比直觉宽**。
3. **口径精度**：「59 个 nodeid 5.8 秒」是 pytest 子进程的墙钟（pytest 自己报
   4.77 秒），而门整体是 **8.0 秒**（含解释器启动与模块导入）。两个数都写进
   §1.1 与 §3.3，不合并成一个「约 6 秒」。

## §9 明确拒绝做的事（避免下一轮走回头路）

1. **不把 `--measure` 并进默认路径**：那会让 `check_all` 依赖 pytest，
   于是它在托管 3.13（无 pytest）上变成红的，远端克隆复核也跑不动。
2. **不在缺 pytest 时静默放行**：必须 rc=2。「测不了就当通过」的门等于没有门。
3. **不为了让反例好写而在测试里点名已登记产物**：那是**登记义务**，不是免费午餐
   （R65 §5.1-2 亲测）。要哑元就取一个**不在**登记表里的名字。
4. **不用 `-rf` / 文本解析取结局**：本机实测 `-rf` 不打印 FAILED 段 ⇒ 会静默少算。
   用 pytest 自己的 `--junit-xml`。
5. **不把 `MEASURE COUNTS` 的数字手写进任何**门禁**判据** —— 它是读数，不是阈值。
6. **不用 `--measure` 自动改写登记表**：登记的价值在于「有人做过一次决定」；
   自动改写会把那点痕迹抹掉。漂移必须**先红**，再由人决定往哪边挪。
7. **不动 `VERSION` / `flow/diagrams` / 不引新依赖 / 不动行尾策略**。
