# 离线安装包归档

这里记录**每个可交付的离线版本**：哪个版本、什么时候出的、多大、改了什么、
文件放在哪。

使用者拿到 `.vsix` 就能装，不需要联网、不需要仓库。

---

## 怎么拿到某一版

1. 在本目录的版本表里找到需要的版本
2. 到 `releases/vsix/` 取对应的文件
3. VS Code → 扩展 → `…` → **从 VSIX 安装**
4. `Ctrl+Shift+P` → `Reload Window`

> **装完必须重载窗口**，否则编辑器仍在跑旧的扩展进程。

## 归档约定

- `vsix/` 下只放**已安装验证过**的包，文件名与版本号一致
- 二进制包本身不进 Git（体积大），需要时由发布脚本重新生成并放入
- 每发布一版，在上表加一行：版本、日期、字节数换算成 KB、一句话变化
- **一句话变化写“用户能感觉到的”，不写内部实现**

---

## 重新生成某个版本

离线包由仓库内脚本产出，**版本号取自扩展清单，产物直接落到 `vsix/`**：

```
python tools/build_vsix.py
```

输出形如 `built <仓库>/releases/vsix/matlabc-lsp-0.6.81.vsix 1108375 bytes`。

脚本结束后，**请在上表顶部补一行**（版本、日期、大小、一句话变化）——
这一行是给人看的，脚本不代写：措辞要写「用户能感觉到的」，不是内部改动。
