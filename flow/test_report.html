③ 本轮修复的两个真缺陷（已在 R924/R925 落地）

setidx 的右值标量未桥接

clip_m.c:30 passing argument 2 of 'mlc_op_setidx' makes pointer from ...

`y(i) = lo`（lo 是 i64 标量）→ 生成 `mlc_op_setidx(&y, lo, i)`，而 C 原型要 `const mlc_array*`。R886 只修了**下标**的桥接，**右值**没修。

局部标量用前未声明

moving_avg_m.c:45 'k' undeclared

`k = lo`（两者都是标量）→ 生成 `k = lo;` 却没有 `int64_t k;`。标量局部量的声明机制没覆盖 `set:` 这条路。
